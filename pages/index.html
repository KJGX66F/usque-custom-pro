🌍 高级：WARP 出口国家 / 地区检测与优选（可选）

🌍 WARP 出口国家 / 地区检测与优选

普通 WARP 不能向 Cloudflare 强制指定国家；这里通过本机 Mihomo API 实测每个 MASQUE 节点的真实出口，再自动选择最符合偏好的节点。

本机检测
工作方式：先运行生成的 Clash/Mihomo 配置，再运行下载的检测脚本。脚本会逐个切换隐藏的“出口检测”组， 通过本地代理访问 Cloudflare Trace / IP 信息接口，记录实际出口国家、地区、IP、PoP、延迟，并测试 ChatGPT HTTP 可达性。 最后把“地区优选”和 AI / PROXY 组切换到最佳候选。它只能在现有 WARP 出口里选择，不能创造 Cloudflare 没有分配给你的国家出口。
⛓ 链式出口（可选，点击展开设置）

让流量先过 WARP、再从你指定的二级代理出去（WARP → 二级代理 → 目标网站）。常见用法：填 Opera 浏览器代理的凭据，或你本机在跑的 opera-proxy 地址，落地就多一个 Opera 出口可选。仅 Clash / Mihomo 格式生效，生成的节点在「🚀 节点选择」里多一个「⛓ 链式出口」。
